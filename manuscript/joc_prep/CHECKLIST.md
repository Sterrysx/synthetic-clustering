# Journal of Classification: submission checklist

Source: JoC *Submission guidelines*, https://link.springer.com/journal/357/submission-guidelines
(fetched 2026-09-29; the plain-text extract is in `joc_guidelines.txt`). Ethics page:
https://link.springer.com/journal/357/ethics-and-disclosures. The "Pre-submission checklist" page
renders client-side and returned no readable text, so it was **not** checked.

Quotes are kept short. **Status updated 2026-09-29 against the v5 blind build** (`manuscript/submission/main_blind.pdf`, `supplementary_blind.pdf`, `title_page.pdf`, produced by `manuscript/build_submission.sh`). The earlier v4 status is in git history.
