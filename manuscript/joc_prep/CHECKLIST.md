# Journal of Classification: submission checklist

Source: JoC *Submission guidelines*, https://link.springer.com/journal/357/submission-guidelines
(fetched 2026-09-29; the plain-text extract is in `joc_guidelines.txt`). Ethics page:
https://link.springer.com/journal/357/ethics-and-disclosures. The "Pre-submission checklist" page
renders client-side and returned no readable text, so it was **not** checked.

Quotes are kept short. The status column refers to the v4 draft and the `joc_prep/` copies.

| # | Requirement | Source quote (JoC page) | Status for v4 / joc_prep |
|---|---|---|---|
| 1 | Manuscript format | "Submit a fully double-spaced, single-column manuscript in English, using a font size of at least 12, with wide margins" | Met by `joc_referee.tex`. Body text is 12 pt on a 24 pt baseline, single column, A4 with 30 mm margins (text block 150 x 237 mm). Captions are double-spaced; table bodies are 12 pt but single-spaced. Sub/superscripts (8 pt) and the text inside the figure PDFs are smaller. |
| 2 | Abstract length | "abstract (of at most 150 words)" | v4 abstract is **147 words** by my count (LaTeX stripped, `$k$` counted as a word). That leaves 3 words to spare, so recount after the re-analysis changes the numbers. |
| 3 | Keywords count | none on the JoC pages | **The JoC pages give no keyword count.** v4 has 5 keywords. |
| 4 | Length limit | "The maximum length is 50 pages for a manuscript" | Referee layout: **41 pp** for the full v4 copy and **35 pp** with Appendices A and B removed (references are pp. 30-35). |
| 5 | Cover letter | "including abstract ..., tables, figures, and a cover letter" | Draft in `cover_letter.md`. The findings are still placeholders. |
| 6 | Double-anonymous review | "It uses a double-blind peer-reviewing system." / ethics page: "peer reviewed (double-anonymous)" | `blind.tex` is tested in `test/main_blind.pdf`: author block hidden, repository URL replaced, one identifying clause hidden, identifying declarations moved to `title_page.tex`, PDF author metadata empty. **Open item:** `chen2025` is a co-author's UPC bachelor's thesis. It is cited in the third person ("extends the line of inquiry opened by Chen (2025)"), which is allowed, but it still points to the authors. The authors should decide whether to keep it, reword it, or anonymise it for review. |
| 7 | Reference style | "initials rather than actual names ... author names are typed in uppercase letters" | `sn-joc.bst` (+ `joc_bib.tex`), shown in `bib_page_*.png`. |
| 8 | Month | "the month of publication of journals should not be included unless every issue begins with page one" | sn-basic already never prints the month; kept in sn-joc. No entry in refs.bib has a month field. |
| 9 | Editions | "for books having more than one edition, the specific edition should be given" | sn-joc prints "2nd ed." from the `edition` field. **No book in refs.bib has an edition field.** Check `johnson1987`, `breiman1984` and `drechsler2011`: if the cited book has later editions, add `edition = {...}`. |
| 10 | Repeated authors | "A horizontal line should not replace authors' names" | Met: names are always written out. |
| 11 | First citation with 3 or more authors | "The first citation in the text to a paper with three or more co-authors should list all the names." | Met by natbib `longnamesfirst` (in `joc_bib.tex`). Checked in `test/main_blind.pdf`: the first citation of breiman1984 prints in full as "(Breiman, Friedman, Olshen, and Stone, 1984)". breiman1984 is cited only once in that copy (its second citation is in the removed Appendix B). The "et al." behaviour was checked on nowok2016: the first of its 5 citations is in full and the other 4 print as "Nowok et al., 2016". |
| 12 | Page/chapter for books | "Citations to books ... for specific details ... should include page number(s) and/or chapter(s)" | **To do:** `\citep{johnson1987}` (l. 268, correlation-matrix construction) and `\citep{breiman1984}` (l. 329, l. 1104) cite specific points and need `\citep[chap.~X]{...}`. |
| 13 | No abbreviated titles | "no abbreviations whatsoever should be used in journal or book titles" | **Check:** `murtagh2017` gives journal = "WIREs Data Mining and Knowledge Discovery" (full title: *Wiley Interdisciplinary Reviews: Data Mining and Knowledge Discovery*). `mullner2011` gives journal = "arXiv preprint arXiv:1109.2378", which should become `@misc` with an eprint. JMIR, npj, PLOS, BMC, IEEE and ACM are parts of official titles. |
| 14 | Data description | "This Journal requires an explicit description of appropriate types of data" / "Defining one or more data matrices as variables is highly recommended" | **To check:** the Methods section describes the data informally. Consider defining the N x p data matrix **X** explicitly near the start of Methods. |
| 15 | Vector/matrix notation | "it is crucial that vectors and matrices be clearly distinguishable from scalar variables" | **Not met in v4:** `x_i`, `\mu_j`, `\mu_j^R` etc. are set in italic like scalars (v4 has only one `\mathbf` in total). Use bold (`\mathbf{x}_i`, `\boldsymbol{\mu}_j`). |
| 16 | Figure size and legibility | "maximum size of figures and tables is a 4.8-inch width x 6.8-inch height ... letters and numbers be large enough" | **Issue:** the figure PDFs are about 7 in wide with 5.2-8 pt text. Reduced to 4.8 in, the smallest labels come out at 3.6-5.2 pt and most text at about 5.5 pt. fig_normal/fig_gamma/fig_scaling are the worst (minimum about 3.6-3.9 pt). Regenerate the figures at 4.8 in width with at least 7-8 pt fonts. |
| 17 | Tables | "Tables are to be numbered with Arabic numerals" / wide margins, compact | Met. The Appendix B cost table (main.tex l. 1092-1111) is already 81 pt too wide in v4 and 137 pt too wide at 12 pt. It must be reflowed when it moves to the supplement. |
| 18 | Code availability | "a statement must be included under the heading 'Code availability' ... after the data availability statement but before the references" | Met in v4 (Declarations section, before `\bibliography`). In blind mode it points to the anonymous mirror placeholder. |
| 19 | Data availability | "authors must add a Data Availability Statement to original research articles" | Met (simulated data; regeneration from seeds). Consider a DOI deposit (placeholder in title page). |
| 20 | Anonymised data/code links | "it is strongly suggested that the authorship in the data is also anonymised" | The GitHub URL `github.com/Sterrysx/...` identifies an author. Create the anonymous mirror (`anonrepourl` in `blind.tex`, currently `https://anonymous.4open.science/r/XXXX`) and check that README/commit metadata in the mirror are anonymised. |
| 21 | Submission contact details | "Please make sure to provide ... E-mail address / Full postal address / Telephone number" | Placeholders in `title_page.tex`. |
| 22 | Competing interests | ethics page: "This journal has a competing interest policy in place." | Placeholder in `title_page.tex` (and v4 Declarations). |
| 23 | Originality / copyright | "the manuscript represents original work not previously published and not being considered elsewhere" | Stated in the cover letter. The overlap with the chen2025 thesis is disclosed there. |
| 24 | Source files on acceptance | "include any additional or altered style files that will be needed to run the paper" | On acceptance, ship `sn-joc.bst`, `joc_bib.tex` and `joc_referee.tex`/`blind.tex` (or drop the last two for the final version). |
